# Development

Guide for maintainers and contributors working on `@common-benefits/sdk`.

For commit conventions, version bump rules, and the release-please workflow that applies across the repo, see the [root DEVELOPMENT.md](../../DEVELOPMENT.md).

## Package structure

```
lib/ts-sdk/
├── lib/
│   └── main.tsp              # TypeSpec entry — imports @common-benefits/core
├── src/
│   ├── index.ts              # SDK entrypoint
│   └── generated/            # Zod schemas emitted by typespec-zod
├── __tests__/
│   └── smoke.spec.ts         # Sanity-check tests
├── dist/                     # Compiled output (generated by `pnpm build`)
├── eslint.config.js
├── tsconfig.json
├── tspconfig.yaml
├── vitest.config.ts
└── package.json
```

## Commands

Run from `lib/ts-sdk/` (or `pnpm --filter @common-benefits/sdk run <cmd>` from anywhere).

| Command              | Description                                                    |
| -------------------- | -------------------------------------------------------------- |
| `pnpm build`         | Compile TypeScript to `dist/`                                  |
| `pnpm typespec`      | Compile `lib/main.tsp` (emits Zod schemas to `src/generated/`) |
| `pnpm clean`         | Remove `dist/`, `tsp-output/`, and `src/generated/`            |
| `pnpm test`          | Run tests with Vitest                                          |
| `pnpm test:watch`    | Run tests in watch mode                                        |
| `pnpm test:coverage` | Run tests with coverage report                                 |
| `pnpm lint`          | Lint and auto-fix with ESLint                                  |
| `pnpm format`        | Format with Prettier and `tsp format`                          |
| `pnpm check:lint`    | Lint without fixing (CI-safe)                                  |
| `pnpm check:format`  | Check formatting without fixing (CI-safe)                      |
| `pnpm check:types`   | Type-check with `tsc --noEmit`                                 |
| `pnpm checks`        | Run all `check:*` scripts                                      |
| `pnpm ci`            | Run checks, build, typespec, and tests (mirrors CI)            |

## Releases

This package is released as **`@common-benefits/sdk`** via release-please.

- **Tag format**: `@common-benefits/sdk@X.Y.Z`
- **Publish workflow**: `CD - Publish @common-benefits/sdk`
- **Environment**: `npm-sdk`
- **Routed commits**: anything that changes files under `lib/ts-sdk/`

See the [root DEVELOPMENT.md](../../DEVELOPMENT.md#releases) for the full release flow, including how to retry a failed publish.
