# Development

Guide for maintainers and contributors working on `@common-benefits/core`.

For commit conventions, version bump rules, and the release-please workflow that applies across the repo, see the [root DEVELOPMENT.md](../../DEVELOPMENT.md).

## Package structure

```
lib/core/
├── lib/                       # TypeSpec source
│   ├── main.tsp              # Library entrypoint
│   ├── fields/               # Domain field types (address, email, money, ...)
│   ├── filters/              # Filter operators (base, date, money, numeric, string)
│   ├── responses/            # Response envelopes (success, error)
│   ├── pagination.tsp        # Pagination types
│   ├── sorting.tsp           # Sort types
│   └── types.tsp             # Primitive types
├── src/
│   ├── index.ts              # JS entrypoint (re-exports lib metadata)
│   └── lib.ts                # Library handle for the TypeSpec compiler
├── dist/                      # Compiled output (generated by `pnpm build`)
├── eslint.config.js
├── tsconfig.json
├── tspconfig.yaml
└── package.json
```

## Commands

Run from `lib/core/` (or `pnpm --filter @common-benefits/core run <cmd>` from anywhere).

| Command             | Description                                           |
| ------------------- | ----------------------------------------------------- |
| `pnpm build`        | Compile TypeScript to `dist/`                         |
| `pnpm watch`        | Compile TypeScript in watch mode                      |
| `pnpm typespec`     | Compile `lib/main.tsp` to verify the TypeSpec library |
| `pnpm clean`        | Remove `dist/` and `tsp-output/`                      |
| `pnpm lint`         | Lint and auto-fix with ESLint                         |
| `pnpm format`       | Format with Prettier and `tsp format`                 |
| `pnpm check:lint`   | Lint without fixing (CI-safe)                         |
| `pnpm check:format` | Check formatting without fixing (CI-safe)             |
| `pnpm check:types`  | Type-check with `tsc --noEmit`                        |
| `pnpm checks`       | Run all `check:*` scripts                             |
| `pnpm ci`           | Run checks, build, and `tsp compile` (mirrors CI)     |

## Releases

This package is released as **`@common-benefits/core`** via release-please.

- **Tag format**: `@common-benefits/core@X.Y.Z`
- **Publish workflow**: `CD - Publish @common-benefits/core`
- **Environment**: `npm-core`
- **Routed commits**: anything that changes files under `lib/core/`

See the [root DEVELOPMENT.md](../../DEVELOPMENT.md#releases) for the full release flow, including how to retry a failed publish.
