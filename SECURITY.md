# Security Policy

If you believe you've found a security vulnerability in CommonBenefits, please report it privately rather than filing a public issue.

**Reporting:** Email `security@common-benefits.example` with a description of the issue and, if possible, reproduction steps. We will acknowledge receipt within a reasonable timeframe and keep you informed as we work on a fix.

Please do not disclose the issue publicly until we've had a chance to address it.
